# 💻 Meninas na Web

Um projeto voltado à tecnologia, à criatividade e à construção de oportunidades para meninas.

## ✨ Sobre o projeto

O **Meninas na Web** é uma iniciativa de extensão que busca incentivar a participação de meninas nas áreas de tecnologia e exatas, aproximando-as do desenvolvimento web por meio de atividades práticas e do contato com esse universo.

Este repositório contém o código-fonte de um site desenvolvido com HTML, CSS e JavaScript.

## 🎯 Objetivo

Desenvolver uma página web que apresente projetos, informações e conteúdos relacionados à iniciativa, utilizando a programação como ferramenta de aprendizado e expressão.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas.
- **CSS3** — estilização e organização visual.
- **JavaScript** — interatividade.
- **Git e GitHub** — versionamento e armazenamento do código.

## 🚀 Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/tallitagg/meu-portifolio-MeninasNaWeb.git
   ```

2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server para visualizar a página.
